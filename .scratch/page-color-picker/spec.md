# 网页取色正式规格

Status: complete

## Problem Statement

用户看到网页中的色块、渐变或图片颜色时，缺少一个不离开当前页面、能从真实渲染像素取样并立即得到常用格式的轻量工具。单纯输入颜色字符串的转换器不能解决“这个屏幕像素到底是什么颜色”的核心问题。

## Solution

提供一个 Manifest V3 Chrome 扩展。用户点击工具栏原生 action 后，扩展先捕获当前可见标签页，再启动不改动原页面样式的取色会话。悬停显示放大预览与颜色，点击确定，Esc 取消。取色面板显示 HEX、RGB、HSL，三种格式均可一键复制；也可输入合法 CSS 颜色并转换。实际取色和用户确认的转换保存为本机近期颜色，可单条删除或全部清空。

## User Stories

1. 作为浏览网页的用户，我想点击扩展工具栏图标立即进入取色，以便不寻找隐藏入口。
2. 作为用户，我想从当前可见网页的真实像素取色，以便图片、渐变和纯色都得到正确结果。
3. 作为高 DPI 或缩放页面的用户，我想取样位置仍准确，以便屏幕坐标差异不导致错色。
4. 作为滚动页面的用户，我想从当前视口取色，以便页面滚动后看到的内容能被正确采样。
5. 作为用户，我想悬停时看到放大预览、取样点和 HEX，以便点击前确认目标。
6. 作为用户，我想点击确定当前颜色，以便结束取色并查看结果。
7. 作为用户，我想按 Esc 取消，以便不产生历史记录且页面恢复原状。
8. 作为用户，我想取色覆盖层不被采入页面快照，以便结果不受扩展界面污染。
9. 作为用户，我想取色期间页面不被误点或滚动，以便操作不会破坏当前页面。
10. 作为用户，我想看到当前颜色的 HEX、RGB、HSL，以便用于不同设计和开发场景。
11. 作为用户，我想点击任一格式即可复制，以便直接粘贴到目标工具。
12. 作为键盘用户，我想看到清晰焦点且可用 Esc 关闭，以便无需鼠标也能恢复页面。
13. 作为用户，我想输入 HEX、RGB、HSL 或常见 CSS 颜色名，以便转换已有颜色。
14. 作为用户，我想非法输入得到中文提示且不覆盖当前结果，以便能修正输入。
15. 作为用户，我想近期颜色自动去重并把最新项置顶，以便快速复用。
16. 作为用户，我想删除单条或清空近期颜色，以便控制本机记录。
17. 作为用户，我想关闭面板再从工具栏重开后仍看到近期颜色，以便跨会话复用。
18. 作为用户，我想在受限制的浏览器内部页看到明确失败提示，以便知道切换到普通网页重试。
19. 作为用户，我想重复点击 action 时得到新的当前页面快照，以便页面变化后取样仍准确。
20. 作为重视隐私的用户，我想截图和历史不离开本机，以便网页内容不被传输。

## Implementation Decisions

- 使用 WXT + Vanilla TypeScript 脚手架，目标为 Chrome Manifest V3。
- 工具栏 action 是唯一原生入口；不设置 popup。action 手势授予 `activeTab`，后台立即使用 `captureVisibleTab` 获取当前视口 PNG，再以 `chrome.scripting.executeScript` 注入运行时取色脚本。
- 不声明常驻 `host_permissions` 或静态全站 content script；权限限于 `activeTab`、`scripting`、`storage`、`clipboardWrite`。
- 页面快照在扩展覆盖层出现前捕获。内容脚本用图片自然尺寸与 `window.innerWidth/innerHeight` 的比例映射坐标，而不是假设固定 DPR，因此覆盖 DPR、缩放与滚动后的当前视口。
- 取色 UI 使用单一 Shadow DOM 宿主，所有样式有边界；取色阶段用捕获期事件阻止页面点击/滚动，结束或取消后清理监听器和临时节点。
- 当前色以标准 RGBA 数值为领域表示；HEX、RGB、HSL 由一个纯函数模块生成。CSS 输入通过浏览器解析能力规范化后再进入同一表示。
- 复制先使用 Clipboard API，失败时使用同步 textarea fallback；每次都显示可观察的中文成功或失败状态。
- 近期颜色使用 `chrome.storage.local`，最多 12 条，按 RGBA 去重、最新置顶；支持单删、全清。截图绝不写入存储。
- 不发起任何网络请求，不包含远程代码、分析或账号系统。

## Testing Decisions

- 最高纯逻辑 seam：颜色领域模块的公开解析、转换和格式化函数；用已知标准色及独立手算结果做 Vitest 行为测试。
- 最高产品 seam：实际安装构建目录后，从 Chrome 工具栏 action 进入，在真实 fixture/普通公开网页完成取色、Esc、复制粘贴、输入、历史关闭重开。
- fixture 包含已知纯色、CSS 渐变、内嵌像素图片、长页滚动区域，并记录预期像素；浏览器证据核对误差容限（纯色每通道 0，渐变/插值每通道不超过 2）。
- 每张实施票和最终候选均以固定 Git 基线执行规范与规格双轴审查，覆盖未提交新文件；发现失败进入 diagnosing-bugs 的可复现闭环。

## Acceptance Criteria

- AC-01：从真实工具栏 action 在普通网页进入取色，悬停预览后点击已知纯色色块，得到精确 HEX/RGB/HSL。
- AC-02：在 DPR/缩放、滚动、渐变与内嵌图片 fixture 上，点击位置映射到页面快照正确像素；覆盖层不污染结果。
- AC-03：取色中按 Esc 后覆盖层消失、页面可继续交互且历史不新增。
- AC-04：HEX/RGB/HSL 三个复制按钮均成功，并在真实页面输入框粘贴得到完全相同文本。
- AC-05：合法 HEX/RGB/HSL/颜色名可转换；非法输入显示中文错误且保留原结果。
- AC-06：近期颜色最新置顶、去重、上限 12，支持单删/清空；关闭原生入口后重开仍保留。
- AC-07：内部页等无法捕获/注入的场景给出可恢复提示或 badge 状态，不留下破坏页面的节点。
- AC-08：最终 `extension/` 是正式构建复制品，清单为 MV3、所有图标存在且尺寸正确，无远程通信与多余权限。
- AC-09：最终候选在 Chrome DevTools MCP 中实际安装、触发 action、执行核心/失败/重开场景，当前指纹门禁通过。

## Out of Scope

- Chrome Web Store 注册、上传、付费、远端发布或 Git push。
- 云同步、账号、多设备历史、网页截图保存、上传、分析与遥测。
- 浏览器窗口边框、其他应用或屏幕区域取色；仅当前 Chrome 标签页可见网页内容。
- Firefox、Safari、Edge 的发布保证。
